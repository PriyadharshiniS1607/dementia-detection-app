# 🧠 Dementia Detection using MRI

This project detects dementia stages using ResNet50 and provides explainable AI using Grad-CAM.

## Features
- MRI Image Upload
- Dementia Stage Prediction
- Grad-CAM Visualization
- PDF Report Generation
- User Login System

## Tech Stack
- Python
- Streamlit
- TensorFlow
- OpenCV

## Run
pip install -r requirements.txt
python -m streamlit run app.py
